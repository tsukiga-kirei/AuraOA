## 当前产品行为

- 全局侧栏保留仪表盘和工作台，下面按智能体归组历史；可折叠、组内新建、跨会话标题搜索、重命名、删除与加载更多。侧栏展开宽度 260px。
- 工具记录默认约 30px 一行，显示来源和状态，点击才展开结果、输入条件和长文本。系统工具、Skill、MCP 一致呈现。
- Markdown 支持标题、列表、表格、引用和代码，统一安全过滤危险 HTML/链接；停止生成及历史失败状态可见。
- 支持多个自定义智能体，以系统提示词和 tool_codes 装配不同业务方案。系统管理员分配租户能力，租户管理员再装配及授权组织角色。
- 已封装九个系统工具；Skill 使用 skill: 标识，MCP 使用 mcp:服务:工具 标识。Skill 是指令指南，目前不执行本地脚本；MCP 支持 Streamable HTTP，不支持 stdio 或旧式独立 SSE 端点。
- 对话主/备用模型、模型思考能力、统一 Token 结算、保留期清理、MCP 数量限制已接通。聊天调用链加入数据管理页 AI 对话分类。
- 模型工具函数名使用稳定别名，避免冒号等业务代码造成模型服务不兼容；日志与界面仍保留业务工具标识。
